仙途UI设计稿

古风水墨修仙MMO游戏 · 全套界面设计系统

以中国传统水墨画为视觉基底，融合黑白灰水墨晕染、朱红印章点缀、暗金云纹边框与仿古宣纸质感， 构建一套兼具东方意境与游戏功能清晰度的修仙MMO UI设计系统。

设计规范

统一视觉语言，贯穿全套11个界面

视觉风格

古风水墨画，传统丹青晕染技法，留白透气，意境悠远。

色彩体系

水墨黑白灰为基底，朱红印章为强调色，暗金云纹为装饰色。

字体系统

标题用毛笔行书书法体，正文用小楷瘦劲字体，层级清晰。

材质边框

仿古宣纸面板，细墨线分隔，暗金云纹回纹边框，四角角花。

启动流程界面

从登录到进入游戏的完整体验链路

登录界面

水墨山水背景 + 卷轴式登录面板，建立第一印象

游戏登录 Launch
层叠水墨远山背景，左侧古松岩石，右侧飞檐楼阁。中央卷轴式登录面板包含账号密码输入框、进入按钮与注册/找回/服务器选项。标题"仙途"为行草书法，配朱红篆刻印章。

加载界面

水墨长卷山水，太极进度条，修仙小贴士

游戏加载 Loading
完整水墨山水长卷，瀑布江流扁舟。中央卷轴进度条配太极加载图标，下方显示修仙小贴士文字。右上角竖排朱红印章，左下角八卦阵装饰。

创建角色（捏人）界面

左侧角色大预览，右侧定制面板，360度旋转

创建角色 / 捏人 Character Create
左侧大型角色半身预览，水墨圆形光晕背景。右侧卷轴定制面板包含性别、门派、体型、面容、发型、服饰选项，底部"重设"与"踏入仙途"按钮。左上角返回按钮。

游戏主界面

进入游戏后的核心HUD布局

世界游玩HUD

全功能战斗界面，左上状态栏、右上小地图、左下聊天、底部技能栏、右下系统菜单

游戏世界主界面 Gameplay HUD
水墨山水场景中，白衣修仙者角色立于山间古道。左上角头像+气血/真元条，右上角小地图+功能按钮，左下角聊天窗口，底部中央8格技能快捷栏+普攻按钮，右下角背包/角色/任务/商城/设置系统菜单。半透明宣纸面板不遮挡场景。

角色系统界面

背包、属性、技能树三大成长系统

背包面板

"乾坤袋"卷轴，30格物品网格+右侧详情区

背包 / 乾坤袋 Inventory
5列6行共30格物品网格，分类标签含全部/装备/消耗品/材料/任务。右侧选中物品详情区显示名称、品质、描述、属性。底部使用/丢弃/整理/拆分按钮，最下方铜钱与灵石货币显示。

角色属性面板

立绘+装备槽+双列属性+深层天赋

角色档案 / 属性 Character
左侧角色水墨立绘，周围环绕6个装备槽（武器/帽子/衣服/饰品/鞋子/项链）。中间角色名"青云子"+门派"青云门"+境界"筑基中期45级"+修为进度条，双列基础属性。右侧深层属性面板：筋骨/灵气/根骨/悟性/幸运。底部换装/修为/称号按钮。

技能树（功法图谱）

四系天赋网状节点，前置依赖解锁路径

功法图谱 / 技能树 Skill Tree
剑修/法修/丹修/体修四系标签切换。三行五列网状节点布局，已学习节点朱红高亮，可学习节点暗金边框，未解锁灰色。节点间墨线连接表示前置依赖。右侧选中技能详情含描述、冷却、消耗、等级。右上角剩余修为点显示。

任务系统界面

任务录列表与详情双栏布局

任务面板

左侧任务列表+右侧任务详情/目标/奖励

任务录 Quest
已接任务/可接任务/已完成分类标签。左侧任务列表显示进度与状态，可交付任务朱红点提示。右侧详情区含任务名、类型标签、描述、目标进度勾选、任务奖励列表。底部追踪任务/放弃任务按钮。

经济系统界面

商城与拍卖行，双轨经济循环

商城（聚宝阁）

左侧分类导航+12格商品卡片，热卖角标

聚宝阁 / 商城 Shop
推荐/限时特惠/装备/丹药/材料/外观/礼包七类导航。4列3行商品卡片网格，含丹药、装备、外观、坐骑、宠物、称号等品类。右上角灵石/仙玉货币显示与充值按钮。热卖商品朱红角标。

拍卖行（万宝拍卖行）

商品列表表格+筛选搜索+出价/上架

万宝拍卖行 Auction House
浏览拍卖/我的拍卖/我的出价/拍卖记录标签。分类+品质+名称搜索筛选。商品表格含图标、名称、品质、价格、卖家、剩余时间、出价按钮。分页控件，右下角上架拍卖大按钮。

世界地图界面

卷轴式全图，八大区域标注

世界大地图

展开的水墨山水长卷，当前位置定位

修仙世界全图 World Map
仿古宣纸卷轴样式，上下木质卷轴杆。八大区域：北荒雪原、万妖谷、青云山、东海蓬莱、魔域深渊、中原皇城、南疆沼泽、西漠流沙。当前位置朱红圆点定位，地点间虚线道路连接。左下角指南针，右下角缩放与传送阵按钮。
