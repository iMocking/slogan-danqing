## 1.3 设计目标

**一句话定位**：以中国传统水墨画为视觉基底，做一款"看起来像一幅会动的画"的修仙游戏。

三条可验收的目标：

1. **视觉辨识度**：任意截取一帧，都能被识别为"水墨修仙"。
   验收：宣纸底 `#f5f0e8` + 墨色 `#2c2c2c` + 朱红 `#8b2500` + 暗金 `#b8860b` 四色贯穿全界面。
2. **界面完整度**：11 个设计稿界面全部可运行、可交互、数据可达。
   验收：见 [08-UI界面开发任务清单](08-UI界面开发任务清单.md)。
3. **系统自洽**：界面展示的每个数据项（境界、修为、气血、灵石……）都有对应系统支撑。
   验收：见 [02-游戏设计文档-GDD](02-游戏设计文档-GDD.md)，无"空壳界面"。

## 1.4 核心体验支柱

| 支柱 | 含义 | 在界面上的体现 |
|---|---|---|
| **水墨意境** | 大面积留白、层叠远山、卷轴与印章，弱化"科技感"边框 | 登录页、加载页、世界地图 |
| **修仙成长** | 境界晋升 > 等级数字，让成长有仪式感 | 角色档案（筑基中期 45 级）、修为进度条、技能树 |
| **轻量操作** | 8 格技能栏 + 单普攻键，降低上手门槛 | 世界主界面 HUD |
| **收藏与交易** | 丹药 / 材料 / 外观 / 坐骑的收集与流通 | 乾坤袋、聚宝阁、万宝拍卖行 |

```

                                    │              │      │
                                    ▼              │      │

                              【成长】功法图谱加点          │
```

## 1.6 范围界定

### MVP（第一个可玩版本，必须完成）

- 启动流程：登录 → 加载 → 创建角色 → 进入世界
- 世界主界面 HUD：角色状态、小地图、聊天、技能栏、系统菜单
- 一个可战斗场景 + 基础敌人 + 掉落
- 角色系统：属性面板 + 装备穿戴
- 背包系统：物品网格 + 使用 / 丢弃 / 整理
- 任务系统：接取 → 追踪 → 交付
- 本地存档

### 第二阶段（长线目标）

- 功法图谱（四系加点）
- 聚宝阁（商城）、万宝拍卖行
- 世界大地图 + 多区域解锁
- 坐骑 / 宠物 / 社交（好友、帮派、邮件、排行）

### 本版本不做

- 实时联网与服务器架构（仅预留接口，见 [05-Godot技术方案](05-Godot技术方案.md) 5.8）
- 3D 场景与 3D 角色（除非确认使用 3D，见 Q2）

## 1.7 术语表

| 术语 | 含义 | 对应界面元素 |
|---|---|---|
| 境界 | 修仙阶段，如练气 / 筑基 / 金丹。等级挂在境界下 | 角色档案「筑基中期」 |
| 修为 | 境界内的经验值，满则突破 | 角色档案修为进度条 |
| 气血 / 真元 | 生命值 / 法力值 | HUD 左上红色 / 蓝色条 |
| 乾坤袋 | 背包的包装名 | ui-04 背包面板 |
| 功法图谱 | 技能树的包装名，四系天赋 | ui-10 技能树 |
| 聚宝阁 | 商城 | ui-07 商城 |
| 万宝拍卖行 | 玩家间交易 | ui-09 拍卖行 |
| 门派 | 职业 / 阵营，如青云门 | 创建角色、角色档案 |
| 灵石 / 仙玉 | 游戏内货币（软通货 / 硬通货） | 背包底部、商城右上、拍卖行 |
| 九宫格 | NinePatchRect，长条素材在 Godot 中的拉伸方式 | 全部按钮、面板、进度条 |
