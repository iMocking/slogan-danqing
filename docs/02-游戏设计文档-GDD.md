## 2.1 世界观与美术基调

水墨画卷即为世界本身：玩家是一名"以画入道"的修仙者，在画卷山水中历练、结丹、飞升。

- **视觉基调**：宣纸留白为底，墨色勾勒为骨，朱红印章点睛，暗金云纹为饰。
- **场景基调**：层叠远山、飞瀑扁舟、古松楼阁（见 `ui-01` / `ui-02` 设计稿）。
- **UI 基调**：面板做成卷轴 / 宣纸，按钮做成印章 / 木牌，进度条做成墨痕。

美术规范见 [03-UI设计规范](03-UI设计规范.md)。

## 2.3 角色与境界体系

### 境界阶梯

设计稿「角色档案」显示 **青云子 · 青云门 · 筑基中期 · 45 级**，可见境界与等级是**两个维度**：
境界决定上限与质变，等级是境界内的小步成长。

| 阶 | 境界 | 等级区间 | 突破条件（建议） |
|---|---|---|---|
| 1 | 练气 | 1–20 | 修为满 + 筑基丹 |
| 2 | 筑基 | 21–45 | 修为满 + 筑基丹 |
| 3 | 结丹 | 46–70 | 修为满 + 金丹 |
| 4 | 元婴 | 71–95 | 修为满 + 元婴丹 |
| 5 | 化神 | 96–120 | 修为满 + 化神丹 |
| 6 | 炼虚 | 121–145 | 修为满 + 天材地宝 |
| 7 | 合体 | 146–170 | 修为满 |
| 8 | 大乘 | 171–200 | 修为满 |
| 9 | 渡劫 | 201+ | 飞升（长线目标） |

- 每个境界内部再分 **初期 / 中期 / 后期 / 圆满** 四段（设计稿显示"中期"）。
- 段位按等级三等分推进，例：筑基 21–45 级 → 初期 21–28 / 中期 29–36 / 后期 37–44 / 圆满 45。
- 「修为」是等级内的经验条，即设计稿角色档案中的进度条。

> ❓ 待确认：满级是否为 200 级；境界名是否沿用传统九境；是否开放飞升（二周目）。

### 职业与门派

设计稿给出 **青云门**，功法图谱给出 **四系：剑修 / 法修 / 丹修 / 体修**。
建议结构：**门派**（叙事与起始资源）与 **修行方向**（四系加点）解耦，玩家可跨系加点。

| 门派（建议） | 起始方向 | 定位 |
|---|---|---|
| 青云门 | 剑修 | 均衡近战（设计稿默认） |
| 玄天宗 | 法修 | 远程爆发 |
| 药王谷 | 丹修 | 治疗 / 增益 |
| 金刚寺 | 体修 | 高血高防 |

> ❓ 待确认：门派数量与名称；门派是否影响属性成长（`ui-11` 捏人页有"门派"选项，说明创建时需选定）。

## 2.4 属性系统

设计稿角色档案为**双栏基础属性 + 五维深层属性**，结构如下。

### 一级属性（战力直接来源）

| 属性 | 作用 | 来源 |
|---|---|---|
| 气血 | 生命值上限 | 境界、体修加点、装备 |
| 真元 | 法力值上限，技能消耗 | 境界、法修加点、装备 |
| 攻击 | 伤害基数 | 武器、加点 |
| 防御 | 减伤 | 防具、体修加点 |
| 命中 / 闪避 | 命中判定 | 加点、装备 |
| 暴击 / 会心伤害 | 爆发能力 | 加点、装备 |
| 移速 | 移动速度 | 鞋子、坐骑 |

### 五维深层属性（设计稿右侧面板）

| 五维 | 影响 |
|---|---|
| 筋骨 | → 气血上限、防御 |
| 灵气 | → 真元上限、法术攻击 |
| 根骨 | → 气血 / 真元自然回复、突破成功率 |
| 悟性 | → 修为获取速度、技能冷却缩减 |
| 幸运 | → 掉落品质、暴击率、拍卖行手续费折扣 ❓ |

**加点规则（建议）**：每次境界突破获得 5 点自由属性点；灵力（技能点）与属性点分账。

> ❓ 待确认：五维是否可自由加点，还是由门派 / 体质固定成长。

## 2.5 功法图谱（技能树）

设计稿 `ui-10`：**四系标签切换 + 三行五列网状节点 + 前置依赖连线 + 右侧技能详情 + 右上剩余修为点**。

### 节点状态

| 状态 | 视觉 | 规则 |
|---|---|---|
| 已学习 | 朱红高亮 | 已投入点数，效果生效 |
| 可学习 | 暗金边框 | 前置节点已满足且点数足够 |
| 未解锁 | 灰色 | 前置未满足或境界不足 |

### 四系定位（建议）

| 系别 | 战斗定位 | 代表机制 |
|---|---|---|
| 剑修 | 近战物理 | 连招层数、剑气 |
| 法修 | 远程法术 | 元素印记、范围爆发 |
| 丹修 | 辅助治疗 | 丹药 buff、持续回复 |
| 体修 | 坦克 | 护体真元、反击 |

**结构建议**：每系 3 行 × 5 列 = 15 个节点，四系共 60 节点；每节点 1–5 级，每级消耗 1 修为点。

> ❓ 待确认：四系是否可同时修满；是否允许洗点（设计稿未出现洗点按钮）。

## 2.6 战斗系统

设计稿 `ui-03` 展示：**底部中央 8 格技能快捷栏 + 右侧普攻按钮**，属**实时动作战斗**。

### 基本规则

- 每个技能消耗**真元**，有**冷却**（设计稿技能详情显示"冷却 / 消耗 / 等级"）。
- 8 个快捷格对应 8 个已装配技能，可在功法图谱中装配。
- 普攻为独立按钮，不消耗真元、无冷却（或极短冷却）。
- 目标选择：❓ 建议无锁定（动作向），或软锁定最近目标。

### 伤害公式（建议，可调）

```
基础伤害 = 攻击 × 技能倍率 + 固定值
减免后   = 基础伤害 × (1 - 防御 / (防御 + 300))
暴击判定 = rand() < 暴击率  →  伤害 × (1 + 会心伤害)
最终伤害 = 减免后 × (1 ± 浮动 5%)
```

### 战斗状态

| 状态 | 效果 |
|---|---|
| 定身 / 眩晕 | 无法移动 |
| 中毒 / 灼烧 | 每帧扣血 |
| 护盾 | 吸收伤害，优先于气血 |
| 真元枯竭 | 无法释放技能 |

## 2.7 背包与物品

设计稿 `ui-04` 乾坤袋：**5 列 × 6 行 = 30 格网格 + 右侧详情区 + 分类标签 + 4 个操作按钮 + 底部货币栏**。

### 分类标签

全部 / 装备 / 消耗品 / 材料 / 任务

### 物品数据结构

| 字段 | 说明 |
|---|---|
| 图标 | 对应 `icons/item/` 素材（剑、葫芦、护甲、灵草、玉佩、灵石） |
| 名称 | 显示名 |
| 品质 | 决定名称颜色与边框 |
| 描述 | 风味文本 |
| 属性 | 加成列表（攻击 +10 等） |
| 堆叠上限 | 消耗品 / 材料可堆叠，装备不可 |
| 售价 | 卖给 NPC 的价格 |

### 操作

| 按钮 | 行为 |
|---|---|
| 使用 | 消耗品：扣除 1 个并生效；装备：穿戴到对应槽位 |
| 丢弃 | 二次确认后移除 |
| 整理 | 按 品质 → 类型 → 名称 重排 |
| 拆分 | 堆叠物拆出指定数量（弹出数量选择框） |

> 设计稿未体现**容量上限**与**扩容**，❓ 建议 30 格为初始容量，可扩展。

### 品质体系（建议）

| 品质 | 颜色（水墨低饱和） |
|---|---|
| 凡品 | `#6b6762` 墨灰 |
| 灵品 | `#4a6b52` 苔绿 |
| 玄品 | `#3d5a7a` 靛青 |
| 地品 | `#7a5a86` 紫檀 |
| 天品 | `#b8860b` 暗金 |
| 仙品 | `#8b2500` 朱红 |

> ⚠️ 需与美术确认：避免高饱和彩虹色破坏水墨基调。

## 2.8 装备系统

设计稿 `ui-05`：角色立绘周围 **6 个装备槽**——武器 / 帽子 / 衣服 / 饰品 / 鞋子 / 项链。

- 装备提供一级属性与五维加成。

- 换装 → 打开装备对比列表；修为 → 修为明细；称号 → 称号墙。

> 设计稿未出现强化 / 精炼 / 镶嵌，❓ 建议放入二阶段。

```
              放弃 ◄── 进行中
```

## 2.10 经济系统

### 货币

| 货币 | 定位 | 获取 | 出现位置 |
|---|---|---|---|
| 铜钱 | 基础软通货 | 任务、怪物掉落 | 背包底部 |
| 灵石 | 高级软通货 | 分解、拍卖、活动 | 背包底部、商城右上 |
| 仙玉 | 硬通货（充值） | 充值 | 商城右上 + 充值按钮 |

### 聚宝阁（商城 · `ui-07`）

- 分类导航：**推荐 / 限时特惠 / 装备 / 丹药 / 材料 / 外观 / 礼包**（7 类）。
- 商品区：**4 列 × 3 行 = 12 个商品卡片**，支持分页。
- 卡片信息：图标、名称、价格、**热卖朱红角标**。
- 货币区：右上角灵石 / 仙玉余额 + 充值按钮。

### 万宝拍卖行（`ui-09`）

- 标签：**浏览拍卖 / 我的拍卖 / 我的出价 / 拍卖记录**。
- 筛选：分类 + 品质 + 名称搜索。
- 列表列：图标、名称、品质、价格、卖家、剩余时间、出价按钮。
- 分页控件 + 右下角**上架拍卖**大按钮。

| 规则（建议） | 值 |
|---|---|
| 上架时长 | 12 / 24 / 48 小时 |
| 手续费 | 成交价 5%（幸运可减免 ❓） |
| 竞价幅度 | 不低于当前价 5% |
| 一口价 | 可选手动设置 |

> ❓ 拍卖行是联网功能，单机版本需用本地模拟数据实现（见 [05-Godot技术方案](05-Godot技术方案.md) 5.8）。

## 2.12 数值框架（初版建议）

| 项 | 建议值 |

| 每级所需修为 | `100 × 等级^1.5` |
