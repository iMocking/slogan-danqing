## UI-01 · 登录

| 项 | 内容 |
|---|---|
| 设计稿 | `design/ui-01-login.png` |
| 所属系统 | 启动流程 |
| 优先级 | P0 |
| 说明 | 层叠水墨远山背景，左侧古松岩石，右侧飞檐楼阁；中央卷轴式登录面板；标题「仙途」为行草书法，配朱红篆刻印章 |

### 布局分区

| # | 分区 | 锚点 | 尺寸 @1920 | 说明 |
|---|---|---|---|---|
| 1 | 背景层 | 全屏 | 1920×1080 | 水墨山水，含远山、古松、楼阁 |
| 2 | 中央登录面板 | 居中 | 约 **717 × 490** | 卷轴式面板（设计稿实测 1020×696） |
| 2.1 | 标题「仙途」 | 面板顶部居中 | 字号 72 | 行草书法体 + 朱红印章 |
| 2.2 | 账号输入框 | 面板内 | 高 56，宽 400 | `input-lg` |
| 2.3 | 密码输入框 | 面板内 | 高 56，宽 400 | 掩码显示 |
| 2.4 | 进入游戏按钮 | 面板底部 | **387 × 88** | 主按钮（设计稿实测 550×125） |
| 2.5 | 次级链接 | 按钮下方 | 字号 16 | 注册 / 找回密码 / 服务器 |
| 3 | 角落装饰 | 四角 | — | 印章、云纹 |

### 元素与交互

| 元素 | 行为 | 校验 / 反馈 |
|---|---|---|
| 账号输入 | 支持中英文、数字、下划线 | 为空时按钮置灰 |
| 密码输入 | 掩码，可切换明文 | 长度 ≥ 6 |
| 服务器选择 | 下拉框 | 默认「青云山·一区」 |
| 进入游戏 | 校验 → 加载 | 失败：面板内红字提示，不弹窗 |
| 回车 | 等价点击「进入游戏」 | — |
| 记住账号 | 复选框 | 本地保存（不保存密码） |

### 数据依赖

`AccountManager`（账号校验，单机版可跳过）、`ServerList`（服务器列表）、`GameConfig`（版本号、公告）

### 验收要点

- [ ] 背景在 16:9 与 21:9 下均不露白
- [ ] 面板居中且随分辨率等比缩放
- [ ] 空账号 / 空密码时按钮为 Disabled 态
- [ ] 标题印章位置与设计稿一致

| 项 | 内容 |
|---|---|
| 设计稿 | `design/ui-02-loading.png` |
| 所属系统 | 启动流程 |
| 优先级 | P0 |
| 说明 | 完整水墨山水长卷（瀑布、江流、扁舟）；中央卷轴进度条配太极加载图标；下方修仙小贴士；右上角竖排朱红印章；左下角八卦阵装饰 |

### 布局分区

| # | 分区 | 锚点 | 尺寸 @1920 | 说明 |
|---|---|---|---|---|
| 1 | 背景长卷 | 全屏 | 1920×1080 | 缓慢横向平移（可选视差） |
| 2 | 进度条 | 居中偏下（y ≈ 62%） | 宽 600，高 32 | 卷轴样式，引用 `panel-scroll-sm` + `bar-frame` |
| 3 | 太极加载图标 | 进度条上方 | 96 × 96 | 匀速自转 |
| 4 | 小贴士文字 | 进度条下方 | 字号 18 | 从文案池随机，3 秒轮换 |
| 5 | 竖排印章 | 右上 | 40 × 144 | 竖排文字 + 朱红 |
| 6 | 八卦装饰 | 左下 | 128 × 96 | 静态 |

### 元素与交互

| 元素 | 行为 |
|---|---|
| 进度条 | `0–100%`，绑定实际资源加载进度 |
| 太极图标 | 恒速旋转（`rotation += delta`，2s/圈） |
| 小贴士 | 每 3 秒淡入淡出切换 |
| 加载完成 | 自动淡出（300ms）→ 进入下一场景 |
| 点击跳过 | 加载完成后可点击立即进入（可选） |

### 数据依赖

`ResourceLoader`（`load_threaded_request` 进度）、`TipsDatabase`（贴士文案池）

### 验收要点

- [ ] 进度条与实际加载进度绑定，不出现"卡在 99%"
- [ ] 异步加载（`load_threaded_request`），主线程不卡顿
- [ ] 太极旋转在任意帧率下匀速

### 元素与交互

| 元素 | 行为 |
|---|---|
| 拖拽预览区 | 角色 360° 旋转（左右拖拽）/ 上下微调视角 |
| 性别 | 男 / 女 切换 → 立即重载模型与选项集 |
| 门派 | 青云门 / 玄天宗 / 药王谷 / 金刚寺 → 影响初始属性与推荐功法 ❓ |
| 体型 / 面容 / 发型 / 服饰 | 多选一，实时预览 |
| 随机 | ❓ 建议增加「随机」按钮 |
| 重设 | 二次确认后恢复默认 |
| 踏入仙途 | 校验角色名 → 写入存档 → 进入 UI-03 |
| 返回 | 提示"未创建的角色将丢失" |

### 数据依赖

`AppearanceOption`（外观选项表）、`SectData`（门派表）、`SaveSystem`（角色创建落盘）

### 验收要点

- [ ] 选项切换后预览在 100ms 内更新
- [ ] 未输入角色名时「踏入仙途」置灰
- [ ] 旋转拖拽不穿透到背景
- [ ] 创建结果可在 UI-05 正确显示（门派、境界=练气初期 1 级）

## 4.2 通用交互约定

| 项 | 约定 |
|---|---|
| 关闭面板 | 右上角关闭按钮；`ESC` 按层级从上往下关闭 |
| 二次确认 | 破坏性操作（丢弃/放弃任务/重设角色/传送）必须确认 |
| 提示 | 轻量操作用 Toast（层级 40），错误用面板内红字 |
| 加载 | 超过 300ms 的操作显示加载指示 |
| 快捷键 | `B` 背包 / `C` 角色 / `Q` 任务 / `K` 功法 / `M` 地图 / `ESC` 关闭 |
| 焦点 | 面板打开时焦点进入面板，`Tab` 循环，防止穿透到 HUD |
| 音效 | 按钮点击、面板开关、物品拾取各配 1 个音效（见 06 章缺口清单） |
