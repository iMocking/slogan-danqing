## 8.13 通用自测清单（每个界面都要跑）

### 功能
- [ ] 所有按钮点击有反馈，无"死按钮"
- [ ] 所有列表可滚动到底部，最后一项不被裁切
- [ ] 所有输入框可输入、可清空、有占位符
- [ ] 面板可用 `ESC` 关闭，`ESC` 层级顺序正确

### 视觉
- [ ] 与设计稿并排比对，分区位置偏差 ≤8px
- [ ] 无素材白边、无拉伸变形、无错位
- [ ] 品质色 / 状态色符合 [03.2](03-UI设计规范.md)
- [ ] 文字不溢出容器、不重叠

### 交互
- [ ] Hover / Pressed / Disabled / Selected 状态齐备
- [ ] 鼠标指针在可点击元素上变为手型
- [ ] 打开面板时 HUD 快捷键不误触发
- [ ] 二次确认只出现一次，重复点击不叠加弹窗

### 健壮性
- [ ] 连续快速点击 20 次不崩溃、不重复扣费
- [ ] 数据为空时显示空状态（不是空白面板）
- [ ] 输出面板无 `push_error` / `push_warning`

### 性能
- [ ] 该界面 Draw Call ≤ 60
- [ ] 打开 / 关闭耗时 ≤ 200ms
- [ ] 关闭后节点已 `queue_free`（内存回落）

### 适配
- [ ] 1280×720 不破版
- [ ] 1920×1080 与设计稿一致
- [ ] 2560×1080（21:9）不破版、不露白
