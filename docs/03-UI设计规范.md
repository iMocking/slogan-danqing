## 3.1 画布、基准分辨率与换算

### 事实来源

| 资产 | 像素尺寸 | 说明 |
|---|---|---|
| `design/ui-01..11-*.png` | **2730 × 1536** | 16:9 界面设计稿 |
| `design/ui-assets-pack/assets/01..06-*.png` | 2730 × 1536 | 素材图集总览 |
| `design/ui-assets-pack/svg/**/*.png` | 不等 | 已切分素材，**导出比例与设计稿不同** |

### 两套换算系数（重要）

设计稿和素材包**不是同一个导出比例**，实测差异约 1.758 倍。必须分别换算：

```
① 设计稿像素 → 1920 基准像素：  目标 = 设计稿px ÷ 1.4219   （≈ × 0.7033）
② 素材 PNG 像素 → 1920 基准像素：目标 = 素材px   ÷ 2.5      （≈ × 0.4   ）
```

### 实测验证（证明系数②成立）

| 元素 | 素材原生 | ÷2.5 | 设计稿 `ui-03` 实测 | ×0.7033 | 结论 |
|---|---|---|---|---|---|
| 气血条宽度 | `bar-hp.png` 739 | 296 | 红色区域宽 298 | 210（✗） | 系数② 成立 |
| 登录主按钮 | `btn-primary-md` 高 226 | 90 | CTA 高约 125 | 88（✓ 同高） | 系数② 成立 |
| 技能栏自洽性 | 8×135 + 288 + 间隙 = 1420 | 8×54+115+间隙≈568 | — | — | 内部自洽 ✓ |

> ⚠️ **踩坑提示**：`svg/**` 下的 PNG 是从图集直接裁切的，**边缘含有展示留白**，
> 且不同素材的留白量不一致。因此：
> - **可拉伸素材**（按钮 / 面板 / 进度条 / 输入框 / 技能栏）→ 只关心**九宫格边距**，尺寸由布局决定；
> - **不可拉伸素材**（图标 / 头像框 / 装备槽 / 装饰）→ 按 `÷2.5` 取目标尺寸，并**重新按内容边界裁切**。

### 基准分辨率

| 项 | 值 |
|---|---|
| 设计画布 | 2730 × 1536（16:9） |
| **基准分辨率（建议）** | **1920 × 1080** |
| 素材导出比 | 2.5×（即 `svg/**` 素材按 1920 基准的 2.5 倍导出） |
| 最小支持 | 1280 × 720 |
| 移动端 | 1920 × 1080 横屏，安全区避让刘海（见 3.12） |

> ❓ Q3：若决定直接以 2730×1536 为基准，则系数① 变为 1.0、系数② 变为 1.758。
> 本套文档全部按 **1920×1080** 编写。

## 3.2 色彩体系

| 名称 | 色值 | 用途 | 占比 |
|---|---|---|---|
| 宣纸底 | `#F5F0E8` | 页面 / 面板底色 | 60% |
| 宣纸浅 | `#FAF5F0` | 卡片、列表条 | 15% |
| 宣纸深 | `#E8E0D0` | 分区底色、表头 | 8% |
| 墨色 | `#2C2C2C` | 正文文字、主轮廓 | 8% |
| 墨灰 | `#6B6762` | 次级文字、禁用态 | 4% |
| 淡墨 | `#B4AEA6` | 分隔线、占位符 | 3% |
| **朱红** | `#8B2500` | **强调：主按钮、印章、当前项、危险操作** | 1.5% |
| 朱红浅 | `#A8452A` | 主按钮悬停 / 高亮 | — |
| 朱红底 | `#FDF0E8` | 标签底、选中行底 | — |
| **暗金** | `#B8860B` | 装饰：云纹边框、可学习节点、等级 | 0.5% |
| 苔绿 | `#4A6B52` | 气血条填充（替代亮红） | — |
| 靛青 | `#3D5A7A` | 真元条填充 | — |

**使用铁律**

1. 朱红是**唯一高饱和强调色**，一屏内出现面积不超过 2%，只用于「当前 / 主要 / 危险」。
2. 禁止引入第三种高饱和色（除品质色外）。
3. 文字对比度：正文 `#2C2C2C` on `#F5F0E8` ≈ 12:1 ✅；辅助文字不得浅于 `#6B6762`。

### 品质色（建议，见 02 章 2.7）

`#6B6762` 凡 → `#4A6B52` 灵 → `#3D5A7A` 玄 → `#7A5A86` 地 → `#B8860B` 天 → `#8B2500` 仙

### 状态色

| 状态 | 色值 |
|---|---|
| 气血 / 危险 | `#8B2500`（低于 30% 时闪烁） |
| 成功 / 可交付 | `#4A6B52` |
| 提示 / 可学习 | `#B8860B` |
| 禁用 | `#B4AEA6`（文字 `#6B6762`，整体不透明度 50%） |

## 3.3 字体体系

| 层级 | 建议字体 | 字号 @1920 | 字重 | 用途 |
|---|---|---|---|---|
| 标题·特大 | 毛笔书法体（Ma Shan Zheng 类） | 72 | 400 | 登录页「仙途」 |
| 标题·大 | 同上 | 40 | 400 | 界面主标题 |
| 标题·中 | 同上 | 28 | 400 | 面板标题 |
| 正文·大 | 衬线（Noto Serif SC） | 20 | 400 | 按钮文字、物品名 |
| 正文·中 | 同上 | 18 | 400 | 通用正文 |
| 正文·小 | 同上 | 16 | 400 | 描述、列表 |
| 辅助 | 同上 | 14 | 400 | 货币、倒计时 |
| 数字 | 等宽或衬线 | 16–20 | 600 | 数值、等级 |

> ⚠️ **授权**：设计稿使用了外部字体链接（`Noto Serif SC`、`Ma Shan Zheng`）。
> - `Noto Serif SC`：SIL OFL，可商用 ✅
> - `Ma Shan Zheng`：SIL OFL，可商用 ✅
> - 若后续替换为未授权商业书法字体，将阻塞上线（见 Q5）。

**规则**

- 行高 = 字号 × 1.6；段间距 = 字号 × 0.8。
- 中文不使用伪粗体；需要加粗时使用 600/700 字重或描边。
- 数字统一使用 600 字重，便于在浅底上辨认。

## 3.5 栅格与间距

- **基础栅格 8px**，所有间距、尺寸取 8 的倍数（4px 为半格，仅用于图标内边距）。
- 页面左右安全边距：**48px**；上边距 32px；下边距 32px。
- 区块间距：24 / 32 / 48。
- 控件内边距（Padding）：按钮水平 24px、垂直 12px；面板 24px；列表项 12×16。

| 间距 Token | 值 | 用途 |
|---|---|---|
| `sp-1` | 4 | 图标与文字 |
| `sp-2` | 8 | 紧密元素 |
| `sp-3` | 16 | 控件间距 |
| `sp-4` | 24 | 区块内间距 |
| `sp-5` | 32 | 区块间 |
| `sp-6` | 48 | 页面分区 |

## 3.12 适配与安全区

| 项 | 策略 |
|---|---|
| 拉伸模式 | Godot `stretch_mode = canvas_items`，`stretch_aspect = expand` |
| 基准视口 | 1920 × 1080 |
| 宽屏（21:9） | `expand` 多出的部分交给 HUD 锚点（左右拉伸），关键内容保持在 16:9 安全框内 |
| 窄屏 / 移动 | 同上；底部技能栏上移避免被手势条遮挡 |
| 安全区 | 顶部 40px、底部 48px、左右 48px |
| 最小字号 | 不得小于 14px @1920 |

**锚点约定（配合 04 章布局分区）**

- 左上（角色状态）：锚左上，偏移 (32, 32)
- 右上（小地图）：锚右上，偏移 (−32, 32)
- 左下（聊天）：锚左下，偏移 (32, −32)
