## 6.3 素材预处理管线

### 目标

把 `svg/**` 的 RGB 素材变成 **RGBA、去留白、已按 0.4 缩放**的 Godot 可用素材。

### 处理步骤

```
原始 PNG (RGB, 带留白)
   │
   ├─① 泛洪填充去背景  →  生成 alpha 通道（带 1px 羽化）
   │
   ├─② 按 alpha 内容边界裁剪  →  去掉展示留白
   │
   ├─③ 等比缩放 ×0.4（= ÷2.5，见 03.1）
   │
   └─④ 输出 RGBA PNG
```

### 脚本：`tools/prepare_ui_assets.py`

```python
#!/usr/bin/env python3
"""
prepare_ui_assets.py — 将 design/ui-assets-pack/svg 下的 PNG 处理为 Godot 可用的透明素材。

用法:
    python tools/prepare_ui_assets.py --src design/ui-assets-pack/svg \
                                      --dst assets/ui --scale 0.4

依赖: Pillow (pip install pillow)
"""
from __future__ import annotations
import argparse, os, sys
import numpy as np
from PIL import Image, ImageDraw, ImageFilter

MAGIC = (255, 0, 255)


def remove_background(img: Image.Image, thresh: int = 32) -> Image.Image:
    """四角泛洪填充 → alpha。返回 RGBA。"""
    rgb = img.convert("RGB")
    tmp = rgb.copy()
    w, h = tmp.size
    for corner in [(0, 0), (w - 1, 0), (0, h - 1), (w - 1, h - 1)]:
        ImageDraw.floodfill(tmp, corner, MAGIC, thresh=thresh)

    arr = np.asarray(tmp)
    is_bg = np.all(arr == np.array(MAGIC), axis=-1)

    # 若背景占比异常（几乎整图），说明该素材不是"图形+留白"，跳过
    if is_bg.mean() > 0.985:
        raise ValueError("背景占比过高（可能是整幅背景图），已跳过")

    alpha = np.where(is_bg, 0, 255).astype(np.uint8)
    out = np.dstack([np.asarray(rgb), alpha])
    result = Image.fromarray(out, "RGBA")

    # 1px 羽化，缓解锯齿
    a = result.getchannel("A").filter(ImageFilter.GaussianBlur(0.6))
    result.putalpha(a)
    return result


def trim(img: Image.Image, pad: int = 1) -> Image.Image:
    """按非透明内容边界裁剪。"""
    bbox = img.getchannel("A").getbbox()
    if bbox is None:
        raise ValueError("全透明图像")
    l, t, r, b = bbox
    l, t = max(0, l - pad), max(0, t - pad)
    r, b = min(img.width, r + pad), min(img.height, b + pad)
    return img.crop((l, t, r, b))


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--src", required=True)
    ap.add_argument("--dst", required=True)
    ap.add_argument("--scale", type=float, default=0.4, help="缩放系数，默认 0.4 (=÷2.5)")
    ap.add_argument("--thresh", type=int, default=32, help="泛洪填充阈值")
    ap.add_argument("--skip-raw", action="store_true", default=True,
                    help="跳过 raw-png/（含烘焙文字，仅作参考）")
    args = ap.parse_args()

    ok = skipped = failed = 0
    for root, _dirs, files in os.walk(args.src):
        if args.skip_raw and os.sep + "raw-png" in root:
            continue
        for name in sorted(files):
            if not name.lower().endswith(".png"):
                continue
            src_path = os.path.join(root, name)
            rel = os.path.relpath(src_path, args.src)
            out_name = name.replace("-", "_")
            dst_path = os.path.join(args.dst, os.path.dirname(rel), out_name)
            os.makedirs(os.path.dirname(dst_path), exist_ok=True)

            try:
                img = Image.open(src_path)
                img = remove_background(img, args.thresh)
                img = trim(img)
                new_size = (max(1, round(img.width * args.scale)),
                            max(1, round(img.height * args.scale)))
                img = img.resize(new_size, Image.LANCZOS)
                img.save(dst_path, "PNG", optimize=True)
                print(f"  OK   {rel:50s} -> {new_size[0]}x{new_size[1]}")
                ok += 1
            except Exception as exc:                       # noqa: BLE001
                print(f"  SKIP {rel:50s} ({exc})")
                skipped += 1
    print(f"\n完成: 成功 {ok} / 跳过 {skipped}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

### 运行

```bash
python tools/prepare_ui_assets.py \
    --src design/ui-assets-pack/svg \
    --dst assets/ui \
    --scale 0.4
```

### 人工复核（必做）

脚本产出是"可用初稿"，**必须美术逐张过目**：

- [ ] 边缘无白边、无锯齿、无残留背景
- [ ] 按钮 / 面板的四角未被裁掉
- [ ] 半透明与描边效果未被破坏
- [ ] 朱红、暗金的色彩未偏移
- [ ] 图标主体居中，四周留白均匀

> 对 A1 问题，**最优解是向设计方索要带 alpha 的导出**（尤其是 7 个 SVG 源可直接重新导出），
> 脚本作为兜底方案。

## 6.4 命名规范

**规则**：`<类别>_<名称>[_<变体>][_<尺寸>].png`，全小写、下划线分隔、仅英文字母数字。

| 类别前缀 | 用途 | 示例 |
|---|---|---|
| `panel_` | 面板 | `panel_scroll_lg.png` |

| `bar_` | 进度条 | `bar_hp.png`、`bar_frame.png` |

## 6.5 Godot 导入设置

| 类型 | 设置 | 值 |
|---|---|---|
| 所有 UI 纹理 | Filter | **Linear**（默认） |
| 所有 UI 纹理 | Mipmaps | **关闭**（UI 不缩放时不糊） |
| 所有 UI 纹理 | Compress Mode | **Lossless**（图标/线条禁止有损） |
| 大背景图 | Compress Mode | VRAM Compressed（可接受轻微损失） |
| 需要九宫格的素材 | 在 `NinePatchRect.texture` 直接引用，不特殊设置 | — |
| 字体 | `FontFile` → `MSDF` | 正文小字号关闭 MSDF |
| 图标 | `Texture2D` → 勾选 `Fix Alpha Border` ❓ | 若出现黑边则开启 |

**禁止**：对 UI 图标使用 `Lossy` 压缩（会产生彩色噪点，破坏水墨纯净感）。

## 6.6 九宫格配置流程

1. 打开 `assets/ui/buttons/btn_primary_lg.png`，在编辑器 `Texture Region` 中观察边框宽度。
2. 在 `StyleBoxTexture` 中设置 `texture_margin_left/right/top/bottom`（03.7 的建议值）。
3. 拖到场景中拉伸成 3 种尺寸（最小 / 常用 / 最大），**目视确认四角不变形**。
4. 记录最终值到 [03-UI设计规范](03-UI设计规范.md) 3.7 表格。
5. 将所有 `StyleBoxTexture` 收敛到 **一个 Theme 资源**，界面不得各自定义。

## 6.7 字体资源

| 用途 | 建议字体 | 授权 | 引入路径 |
|---|---|---|---|
| 标题（书法） | Ma Shan Zheng | SIL OFL ✅ | `assets/fonts/MaShanZheng-Regular.ttf` |
| 正文 | Noto Serif SC（Regular / SemiBold） | SIL OFL ✅ | `assets/fonts/NotoSerifSC-Regular.otf` |
| 数字 | 同上 + `tnum` 特性，或思源等宽 | SIL OFL ✅ | — |

**引入步骤**

1. 下载 TTF/OTF 放入 `assets/fonts/`。
2. 在 Godot 中创建 `FontFile` 资源（自动生成 `.import`）。
3. 子集化（仅保留常用汉字 3500 + 标点）可将体积从 ~20MB 降到 ~3MB。
4. 在 `xian_tu_theme.tres` 中设为 `default_font`，并配置字号阶梯（03.3）。

> ⚠️ 设计稿 HTML 中引用了 `https://miaoda.feishu.cn/fonts/css2?...`，**不要在生产环境联网加载字体**。
> 必须本地化到 `assets/fonts/`。
